# Зачем нужна обвязка агента для Claude Code

Агент Claude Code пишет код быстро и ошибается одинаковыми способами. Обвязка не делает модель умнее. Она делает повторяющиеся ошибки дорогими или невозможными для сокрытия.

## Какие сбои закрываются

| Сбой | Что происходит | Что делает maxforge-claude |
|---|---|---|
| «Готово» без доказательств | Агент рапортует об успехе без вывода тестов и скриншота | `qa-verify` требует воспроизведение или матрицу требование-доказательство; агент `verifier` пытается опровергнуть утверждение |
| Пропущенные или подогнанные тесты | Падающий тест удаляют или ослабляют | Правила воркеров запрещают ослаблять тест; ревьюеры и verifier проверяют дифф |
| Push в `main` | Прямой push, force-push, `--no-verify` | `hooks/guard-bash.py` отклоняет команду |
| Мёртвые кнопки | UI проходит ревью по скриншотам, а половина элементов ничего не делает | `tools/dead-clicks.mjs` нажимает каждый элемент; гейт PR требует его отчёт |
| Потеря контекста | После сжатия пропали цель, ветка и следующий шаг | `hooks/precompact-handoff.py` и `hooks/session-restore.py` |
| Расход контекста впустую | Большие выгрузки, повторные чтения, циклы sleep | `hooks/token-guard.py`, `hooks/dump-nudge.py`, `hooks/bg-router.py` |

## Инструкции и хуки

Правило в `CLAUDE.md` это просьба. Хук это код, который срабатывает на вызов инструмента и может вернуть отказ, поэтому правило, которое обязано выполняться, живёт в хуке. Для всего, что нельзя проверить механически (как ревьюить, как писать спецификацию), обвязка всё равно поставляет инструкции: `rules/*.md` и скиллы.

## Честная цена

Обвязка тратит больше токенов, чем чистый Claude Code. В собственном A/B-замере автора те же задачи потребовали примерно в 1,49 раза больше токенов при равном качестве. Дополнительный расход дают независимое ревью, проход verifier, прогоны UI QA, файлы передачи и чтение правил. Заявлений об экономии проект не делает.

Часть хуков сокращает потери внутри этого бюджета (блокируют выгрузку файлов целиком, повторные чтения, пустые ожидания), в сумме расход всё равно выше.

Используйте её там, где неверное «готово» дороже лишних токенов: общие репозитории, боевой код, UI, который должен реально работать, работа, за которой вы не следите построчно. Для одноразового скрипта чистый Claude Code дешевле и достаточен.

## Чем она не является

- Не улучшением модели: качество кода Claude она не меняет.
- Не песочницей: хуки отклоняют известные плохие команды, но не делают безопасной произвольную.
- Не привязана к одному стеку: правила для Laravel/PHP, Vue/TypeScript и Python включены, гейты от стека не зависят.
