# FAQ

## Экономит ли он токены?

Нет. Он дороже: около 1,49 раза по токенам в A/B-замере автора при равном качестве. Обвязка покупает принуждение и проверку. Часть хуков убирает потери внутри неё, но в сумме расход выше.

## Конфликтует ли он с моим CLAUDE.md?

Плагин его никогда не правит. Правила попадают в `~/.claude/rules/maxforge/`. Если ваш `CLAUDE.md` говорит не то, что правило, модель видит оба текста и может последовать любому; хуки работают независимо от текста. Держите проектный `CLAUDE.md` в виде фактов (стек, команды, порты), а процесс отдайте правилам.

## Windows и macOS?

Хуки на stdlib Python 3.10+. Автор работает на Linux, часть инструментов это bash-скрипты (`tools/wt-new.sh`, `tools/q`). На macOS должно работать, но матрицы тестов нет; на Windows используйте WSL. О проблемах платформы сообщайте issue.

## Как отключить один хук?

Обходы на один запуск; использовать их стоит осознанно и называть пользователю причину:

| Переменная | Отключает |
|---|---|
| `CLAUDE_GUARD_OFF=1` | гейт git и разрушительных команд, дизайн-гейт, гейт правил |
| `CLAUDE_ALLOW_SECRETS=1` | сканер секретов для одного коммита |
| `CLAUDE_TOKEN_GUARD_OFF=1` | token guard |
| `CLAUDE_BG_ROUTER_OFF=1` | фоновую маршрутизацию |

Чтобы убрать хук насовсем, отключите плагин в `/plugin`.

## Телеметрия?

Нет. Плагин не отправляет данные об использовании, логи остаются на вашей машине. Одно уточнение: `hooks/project-sync.py` может сделать HTTP GET по адресам deployed SHA, которые вы сами указали в своём `docs/project/PROJECT.md`, чтобы показать, что сейчас выкачено.

## Нужны ли gh и Node?

Нет. Без `gh` PR открываются вручную. Без Node UI-инструменты (`ui-qa`, `dead-clicks`) недоступны, поэтому дизайн-гейт для UI-PR можно пройти только с явным объяснением n/a.

## Можно ли взять только часть?

Да. Хуки работают без вызова скиллов. Скиллы и агенты ничего не стоят, пока их не используют.
