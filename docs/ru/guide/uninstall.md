# Удаление

```text
maxforge uninstall
/plugin uninstall maxforge-claude@maxforge-claude
```

## Что удаляется, что остаётся

| Что | После удаления |
|---|---|
| Файлы плагина (хуки, скиллы, агенты, инструменты) | удаляет `/plugin uninstall` |
| `~/.claude/rules/maxforge/` | удаляет `maxforge uninstall`; резервная копия setup остаётся |
| Настройки, влитые через `--settings` | восстановите из копии, которую сделал setup |
| Playwright в каталоге данных плагина (`--node`) | остаётся, пока вы не удалите `$CLAUDE_PLUGIN_DATA` |
| Логи и состояние (`~/.claude/state`, `~/.claude/logs`) | остаются; удалите вручную, если не нужны |
| Файлы `progress.md`, закоммиченные в ваших ветках задач | остаются, это обычная история git |

После удаления запустите `maxforge doctor` и убедитесь, что ничто не ссылается на плагин. Чтобы приостановить, а не удалять, отключите плагин в `/plugin` или используйте один [обход](/ru/guide/faq#как-отключить-один-хук).
